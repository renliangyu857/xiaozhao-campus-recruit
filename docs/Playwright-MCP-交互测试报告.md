# 校招聚合站 - Playwright MCP 交互测试报告

## 一、用户交互功能清单（分析结果）

| 编号 | 功能模块 | 具体交互 | 前置条件 |
|------|----------|----------|----------|
| F1 | 首页-加载 | 打开首页，展示「最新职位」区域、筛选栏、列表或「暂无相关职位」 | 无 |
| F2 | 首页-筛选 | 选择行业/类型/截止/地点/岗位关键词，点击「查询筛选」 | 无 |
| F3 | 首页-今日新增 | 点击「今日新增」开关，再点「查询筛选」 | 无 |
| F4 | 首页-登录 | 点击「微信登录」，在 prompt 输入 code，登录成功后面板显示用户信息或「免费剩余」 | 无 |
| F5 | 首页-免费次数 | 未登录或非 VIP 时多次「查询筛选」，第 4 次出现「今日免费次数已用完」弹层 | 已登录且非 VIP |
| F6 | 首页-付费弹层 | 弹层中点击「立即开通会员」跳转会员页；点击「暂不需要，明天再来」关闭弹层 | 已触发 F5 |
| F7 | 首页-职位卡片 | 若有职位：状态下拉框切换（需登录）、点击「简章」「去投递」链接 | 有职位数据；改状态需登录 |
| F8 | 导航 | 点击「招聘列表」「进度统计」「会员中心」正确跳转 | 无 |
| F9 | 进度页-未登录 | 进入进度统计页显示「请登录后查看投递统计」和「去登录」 | 未登录 |
| F10 | 进度页-已登录 | 显示「我的投递看板」、总投递/笔试中/面试中等统计、图表 | 已登录 |
| F11 | 会员页 | 显示套餐列表或「当前为普通用户」；点击某套餐触发确认与下单（需登录） | 无 |
| F12 | 会员页-已 VIP | 若已 VIP 显示「尊贵的 VIP 会员」及有效期 | 已开通 VIP |
