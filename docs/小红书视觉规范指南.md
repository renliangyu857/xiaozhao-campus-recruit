# 小红书视觉规范指南

**版本**：v1.0
**更新日期**：2026-02-28
**适用范围**：小红书笔记封面、配图、个人主页

## 一、基础规范

### 1.1 尺寸标准

| 用途 | 尺寸比例 | 推荐尺寸 | 文件格式 | 文件大小 |
|------|---------|---------|---------|---------|
| **封面图** | 3:4 | 900×1200px | PNG/JPG | ≤5MB |
| **横版配图** | 4:3 | 1200×900px | PNG/JPG | ≤5MB |
| **方版图** | 1:1 | 1080×1080px | PNG/JPG | ≤5MB |
| **竖版长图** | 3:4/9:16 | 900×1600px | PNG/JPG | ≤5MB |
| **头像** | 1:1 | 500×500px | PNG | ≤1MB |

### 1.2 安全区域

```
┌─────────────────────────────┐
│         顶部安全区 100px      │ ← 避免重要内容被遮挡
├─────────────────────────────┤
│                             │
│      主视觉区域 700px        │ ← 核心内容区域
│                             │
├─────────────────────────────┤
│        底部安全区 100px       │ ← 避免被系统UI遮挡
└─────────────────────────────┘
           900px
```

**关键原则**：
- 标题文字距离上下边缘至少80px
- 核心视觉元素集中在中间700px区域
- 避免在四角放置重要信息（可能被系统UI覆盖）

## 二、配色方案

### 2.1 主色调

| 色彩名称 | 色值 | 适用场景 | 心理暗示 |
|---------|------|---------|---------|
| **珊瑚红** | `#FF6B6B` | 紧迫感、促销、DDL提醒 | 紧迫、重要 |
| **电光蓝** | `#4ECDC4` | 工具类、效率类 | 专业、冷静 |
| **阳光黄** | `#FFE66D` | 福利、活动、VIP | 温暖、价值 |
| **薄荷绿** | `#95E1D3` | 进度、成功、数据 | 清新、成长 |
| **深紫** | `#6C5CE7` | VIP、高端、专属 | 尊贵、稀缺 |

### 2.2 配色组合

**组合1：活力进取**
```
主色：#FF6B6B（珊瑚红）
辅色：#FFE66D（阳光黄）
背景：渐变（珊瑚红→柔粉）
文字：#2D3436（深灰）
```
适用：信息聚合、功能介绍类封面

**组合2：专业冷静**
```
主色：#4ECDC4（电光蓝）
辅色：#95E1D3（薄荷绿）
背景：渐变（薄荷绿→电光蓝）
文字：#2D3436（深灰）
```
适用：进度管理、数据分析类封面

**组合3：尊贵稀缺**
```
主色：#6C5CE7（深紫）
辅色：#FFE66D（阳光黄）
背景：渐变（深紫→浅紫）
文字：#FFFFFF（白色）
```
适用：VIP、付费转化、内推码类封面

**组合4：紧急行动**
```
主色：#FF6B6B（珊瑚红）
辅色：#FFE66D（阳光黄）
背景：渐变（珊瑚红→阳光黄）
文字：#2D3436（深灰）
```
适用：DDL提醒、截止倒计时类封面

### 2.3 配色原则

1. **对比度**：文字与背景对比度至少4.5:1
2. **色彩数量**：单图不超过3种主色+1种中性色
3. **品牌一致性**：同一账号保持2-3种核心配色
4. **情绪匹配**：紧急用暖色、专业用冷色、福利用亮色

## 三、字体规范

### 3.1 字体选择

| 类型 | 推荐字体 | 备用字体 | 使用场景 |
|------|---------|---------|---------|
| **标题** | 思源黑体 Heavy | PingFang SC Bold | 封面主标题 |
| **正文** | 思源黑体 Regular | PingFang SC Regular | 说明文字 |
| **英文** | Helvetica Bold | Arial Bold | 英文标题 |
| **数字** | DIN Alternate Bold | Helvetica Neue | 数据展示 |

### 3.2 字号层级

```
封面图（900×1200px）：

超大标题：80-120px
用途：核心关键词（如"校招信息"）
示例："一站搞定"、"内推码"

大标题：50-70px
用途：副标题、强调信息
示例："不用再关注100个公众号"

中标题：35-45px
用途：功能点、特点
示例："聚合全网"、"智能筛选"

正文：24-32px
用途：说明文字、CTA
示例："建议收藏 | 每日更新"

小字：18-22px
用途：标签、备注
示例："新用户专属"
```

### 3.3 字体排版原则

**对齐方式**：
- 标题：居中对齐（营造稳定感）
- 列表：左对齐（便于阅读）
- 按钮：居中对齐（强调CTA）

**行距与字距**：
- 标题行距：1.1-1.2倍字号
- 正文行距：1.4-1.6倍字号
- 标题字距：-0.02em至0（紧凑有力）

**文字效果**：
- 避免使用描边（显得廉价）
- 谨慎使用阴影（如需使用，用柔和投影）
- 保持文字平整（不使用渐变文字）

## 四、版式规范

### 4.1 封面结构模板

**模板A：居中大标题型**
```
┌─────────────────┐
│                 │
│   [装饰元素]     │
│                 │
│  超大标题文字    │  ← 核心卖点
│  超大标题文字    │
│                 │
│  副标题说明      │  ← 一句话解释
│                 │
│  [功能标签]      │  ← 3个特点pill
│                 │
│  底部CTA        │  ← 引导行动
│                 │
└─────────────────┘
```
适用：功能介绍、产品卖点

**模板B：列表展示型**
```
┌─────────────────┐
│   标题文字       │
│   标题文字       │
│                 │
│  □ 列表项1      │
│  □ 列表项2      │  ← 核心内容
│  □ 列表项3      │
│  □ 列表项4      │
│                 │
│  [进度条/数据]   │  ← 可视化
│                 │
│   底部说明       │
└─────────────────┘
```
适用：资源汇总、进度展示、DDL提醒

**模板C：卡片弹窗型**
```
┌─────────────────┐
│                 │
│  ┌───────────┐  │
│  │           │  │
│  │  卡片内容  │  │  ← 白色卡片
│  │  核心信息  │  │
│  │           │  │
│  └───────────┘  │
│                 │
│   背景装饰      │  ← 渐变/图形
│                 │
└─────────────────┘
```
适用：福利活动、VIP推广、内推码

### 4.2 元素间距规范

```
┌─────────────────┐
│    60px 边距    │
│  ┌───────────┐  │
│  │           │  │
│  │  内容区    │  │
│  │           │  │
│  └───────────┘  │
│    60px 边距    │
└─────────────────┘

元素间距：
- 大模块间距：60-80px
- 中模块间距：30-40px
- 小模块间距：15-20px
- 文字与图标：10-15px
```

### 4.3 图形元素

**圆角规范**：
- 大卡片：30px圆角（友好感）
- 按钮：25-35px圆角（胶囊形）
- 小标签：15-20px圆角（柔和）

**装饰图形**：
- 使用简单的几何形状（圆、椭圆、矩形）
- 透明度控制在10-30%（不抢主体）
- 避免复杂图案和纹理

## 五、内容模板库

### 5.1 痛点共鸣型封面

**结构**：
1. 顶部：痛点关键词（大字）
2. 中部：痛点描述（一句话）
3. 底部：解决方案暗示

**配色**：珊瑚红+阳光黄（情感共鸣）
**示例文案**：
- "校招信息太散了"
- "投了50家记不清"
- "差点错过DDL"

### 5.2 功能种草型封面

**结构**：
1. 顶部：核心功能（大字）
2. 中部：3个特点（Pill标签）
3. 底部：CTA引导

**配色**：电光蓝+薄荷绿（专业可信）
**示例文案**：
- "投递进度一目了然"
- "3秒精准筛选"
- "智能管理求职"

### 5.3 资源分享型封面

**结构**：
1. 顶部：资源类型
2. 中部：具体资源列表
3. 底部：获取方式

**配色**：深紫+阳光黄（尊贵价值）
**示例文案**：
- "大厂内推码汇总"
- "本周校招信息"
- "速收藏"

### 5.4 紧急行动型封面

**结构**：
1. 顶部：警告标识
2. 中部：截止公司列表
3. 底部：立即行动CTA

**配色**：珊瑚红为主（紧迫感）
**示例文案**：
- "本周截止"
- "紧急"
- "最后机会"

### 5.5 福利活动型封面

**结构**：
1. 顶部：VIP/福利标识
2. 中部：福利内容
3. 底部：领取按钮

**配色**：深紫+阳光黄（尊贵+价值）
**示例文案**：
- "VIP体验免费领"
- "限时优惠"
- "手慢无"

## 七、检查清单

### 发布前自检（Cover Checklist）

- [ ] 尺寸是否为900×1200px（3:4）
- [ ] 文字是否在安全区域内（距离边缘≥80px）
- [ ] 主标题是否清晰可见（字号≥80px）
- [ ] 配色是否协调（≤3种主色）
- [ ] 文字与背景对比度是否足够
- [ ] 是否包含明确的CTA（引导行动）
- [ ] 图片是否≤5MB
- [ ] 在小图预览时是否仍能看清主题

### 品牌一致性检查

- [ ] 是否使用了规定的配色方案
- [ ] 字体是否统一（同一账号）
- [ ] 风格是否一致（同一系列笔记）
- [ ] Logo/品牌元素位置是否统一

## 九、常见问题

**Q1：为什么我的封面在小图预览时看不清？**
A：主标题字号要足够大（≥80px），避免过多细节，确保缩略图时能看清核心关键词。

**Q2：可以用照片做背景吗？**
A：可以，但需加半透明蒙版（黑色/白色，透明度50-70%）确保文字可读。

**Q3：一个系列笔记要保持完全一致吗？**
A：建议保持80%一致（配色、字体、版式），20%变化（标题、具体内容）避免审美疲劳。

**Q4：封面图可以放二维码吗？**
A：小红书封面不支持点击，建议放在笔记内页第一张图或评论区。

**Q5：如何判断配色是否协调？**
A：使用配色工具（如Coolors）生成配色方案，或参考本指南的配色组合。
