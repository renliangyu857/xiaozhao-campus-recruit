# 微信登录配置说明

本文档说明如何将模拟登录切换为真实的微信公众号登录。

## 一、获取微信配置

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 确认你的公众号是**已认证的服务号**
3. 进入「开发 → 基本配置」，获取：
   - **AppID** (开发者ID)
   - **AppSecret** (开发者密码)

## 二、配置环境变量

在 `.env.local` 文件中添加：

```bash
# 微信公众号登录配置
WECHAT_APP_ID=wxYOUR_APP_ID_HERE
WECHAT_APP_SECRET=YOUR_APP_SECRET_HERE
```

> 不要把真实的 `WECHAT_APP_SECRET` 提交到仓库；建议仅保留占位符，并通过本地/部署环境变量注入。

## 三、微信公众平台配置

### 1. 网页授权域名

**路径**：设置与开发 → 公众号设置 → 功能设置 → 网页授权域名

添加你的域名（如 `your-domain.com`）：
- 下载 `MP_verify_xxx.txt` 文件
- 放到网站根目录（使 `https://your-domain.com/MP_verify_xxx.txt` 可访问）
- 在后台点击「保存」

### 2. IP 白名单

**路径**：开发 → 基本配置 → IP白名单

添加你的服务器公网 IP 地址。

## 五、登录流程

### H5 场景（微信内打开网页）

1. 用户点击「登录」按钮
2. 检测到是微信浏览器，调用 `/api/auth/wechat/url`
3. 跳转到微信授权页
4. 用户确认授权
5. 微信回调到 `/api/auth/wechat/callback`
6. 后端获取用户信息，创建/更新数据库记录
7. 设置 Session，跳转回首页

### PC 场景（浏览器访问网页）

1. 用户点击「登录」按钮
2. 检测到非微信浏览器，显示二维码弹窗
3. 调用 `/api/auth/qrcode` 生成票据和二维码
4. 前端轮询 `/api/auth/qrcode/poll?ticket=xxx`
5. 用户用微信扫码
6. 手机端确认授权
7. PC 端检测到登录成功，刷新页面

## 六、开发测试

在配置未完成前，系统会自动回退到**模拟登录模式**：
- 弹窗提示用户输入任意 code
- 后端将 code 视为 openId 创建用户
- 用于本地开发和测试

## 七、常见问题

### 1. 微信授权报错 "redirect_uri 参数错误"

检查：
- 回调地址域名是否与「网页授权域名」一致
- 必须使用 HTTPS
- 域名必须已备案

### 2. 本地开发无法测试

微信网页授权需要真实域名，本地 `localhost` 无法直接测试。建议：
- 使用 ngrok 等工具生成临时域名
- 在公众号后台添加测试域名
- 或者使用模拟登录模式

### 3. 二维码一直显示过期

检查：
- Redis 配置是否正确（可选，无 Redis 会使用内存缓存）
- 服务器时间是否准确
- 轮询接口是否正常响应

## 八、接口汇总

| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/auth/wechat/url` | GET | 获取微信授权 URL |
| `/api/auth/wechat/callback` | GET | 微信回调处理 |
| `/api/auth/qrcode` | GET | 生成扫码登录二维码 |
| `/api/auth/qrcode/poll` | GET | 轮询登录状态 |

## 九、安全建议

1. **生产环境必须设置** `SESSION_SECRET`，不要使用默认值
2. **保护好 `WECHAT_APP_SECRET`**，不要提交到代码仓库
3. 微信配置建议仅在后端环境变量中设置，不要暴露给前端

---

配置完成后，重启应用即可生效。
