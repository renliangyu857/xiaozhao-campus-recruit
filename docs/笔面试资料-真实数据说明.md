# 笔面试资料页 - 真实数据说明

页面**优先**从 **`public/pan-export.txt`**（百度网盘自带导出格式）加载；若无则从 **`public/pan-export.json`** 加载；都无则使用代码内置示例。

---

## 方式一：百度网盘自带导出（推荐）

1. 在百度网盘分享目录中，使用 **「导出目录」** 功能，将目录清单保存为 TXT。
2. 将导出的 TXT 文件**重命名为 `pan-export.txt`**，放入项目的 **`public/`** 目录（覆盖已有即可）。
3. 重新构建或刷新前端，笔面试资料页会解析该 TXT 并展示**真实文件名与路径**。

**格式说明**：导出的树形文本每行形如 `│   ├── 文件名`，程序会解析层级得到路径，并只列出带扩展名的文件（如 .pdf、.doc、.jpg），用于表格展示。题库大小在 TXT 中无信息时显示为「—」，文件数为解析得到的文件条数。

---

## 方式二：自定义 JSON（可选）

若希望自定义统计（题库大小、最后更新）或已有结构化数据，可使用 JSON：

1. 将数据整理成 `public/pan-export.json`，结构如下：

```json
{
  "stats": {
    "totalSize": "7.95TB",
    "fileCount": 385259,
    "lastUpdated": "2025-10"
  },
  "items": [
    {
      "displayId": 1,
      "name": "某某资料.pdf",
      "path": "一级目录 / 二级目录",
      "size": "1.2MB",
      "format": "pdf"
    }
  ]
}
```

2. 若同时存在 `pan-export.txt` 与 `pan-export.json`，页面**优先使用 TXT**。
