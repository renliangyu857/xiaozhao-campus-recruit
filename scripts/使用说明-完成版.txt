一、已完成的功能
======================================================================

1. 每日自动生成小红书笔记图片
   - Notion 风格极简设计
   - 1536x1536 (2K) 高质量
   - 每个类别生成 4 张图片

2. 支持的职位类别
   - 国央企
   - 互联网
   - 外企

3. 定时任务
   - 每天早上 10:00 自动运行
   - 中国时区 (Asia/Shanghai)

4. 生成内容
   - 4 张图片（封面 + 2张内容 + 结尾）
   - 小红书笔记文案 (note-text.txt)
   - 源文件和分析文件

======================================================================
二、使用方式
======================================================================

方式一：立即测试生成（推荐先测试）
  1. 打开命令行，进入项目目录
  2. 运行：npm run xhs:generate
  注意：完整运行需要约 10-15 分钟（需要等待 API 速率限制）

方式二：启动定时任务
  1. 打开命令行，进入项目目录
  2. 运行：npm run xhs:schedule
  3. 保持窗口打开，定时任务会在每天 10:00 运行

方式三：使用 PowerShell 脚本（Windows 推荐）
  1. 右键点击 "scripts/立即生成.ps1"
  2. 选择 "使用 PowerShell 运行"

  或

  1. 右键点击 "scripts/启动定时任务.ps1"
  2. 选择 "使用 PowerShell 运行"

四、关于小红书发布
======================================================================

重要说明：脚本不包含自动发布功能！

原因：
1. 小红书没有公开的 API 用于自动发布
2. 自动发布存在账号安全风险
3. 需要处理复杂的验证码和登录流程

推荐的发布方式：

1. 等待定时任务生成内容（或手动运行生成）
2. 打开 daily_output/xhs-images/{类别}-{日期}/ 目录
3. 复制 note-text.txt 中的文案
4. 手动上传 4 张图片到小红书
5. 粘贴文案并发布

五、常见问题
======================================================================

Q: 定时任务没有运行？
A: 检查：
   1. 脚本窗口是否保持打开
   2. 系统时间是否正确
   3. 控制台是否有错误信息

Q: 图片生成失败？
A: 可能原因：
   1. API 密钥失效或配额用完
   2. 网络连接问题
   3. API 速率限制（脚本已包含等待时间）

Q: 如何修改定时时间？
A: 编辑 scripts/scheduled-runner.js 中的 cron 表达式：
   '0 0 10 * * *' 表示每天 10:00
   '0 30 9 * * *' 表示每天 9:30

Q: 数据库连接失败？
A: 确保 .env.local 文件存在并包含 DATABASE_URL
