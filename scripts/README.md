
# 小红书每日定时任务

自动生成并准备发布小红书笔记的定时任务系统。

## 📦 功能

1. **自动图片生成** - 使用 Notion 风格生成职位信息图片
2. **定时任务** - 每天早上 10 点自动运行
3. **多类别支持** - 支持国央企、互联网、外企三个类别
4. **笔记文字生成** - 自动生成小红书笔记文案

## 🚀 快速开始

### 首次使用

1. **安装依赖**
   ```bash
   npm install
   ```

2. **立即测试生成**
   - 双击 `立即生成.bat`（Windows）
   - 或运行 `npm run xhs:generate`

3. **启动定时任务**
   - 双击 `启动定时任务.bat`（Windows）
   - 或运行 `npm run xhs:schedule`

| 文件 | 说明 |
|------|------|
| `daily-xhs-generator.js` | 核心生成脚本 |

| `启动定时任务.bat` | Windows 定时任务启动脚本 |

## ⏰ 定时任务设置

- **时间**: 每天早上 10:00
- **时区**: Asia/Shanghai（中国时区）
- **注意**: 需要保持脚本窗口打开

### 修改定时时间

编辑 `scheduled-runner.js` 中的 cron 表达式：

```javascript
// 格式: 秒 分 时 日 月 星期
const cronExpression = '0 0 10 * * *';  // 每天 10:00
```

常见 cron 表达式：
- `0 0 10 * * *` - 每天 10:00
- `0 30 9 * * *` - 每天 9:30
- `0 0 8,18 * * *` - 每天 8:00 和 18:00

## ⚠️ 关于小红书自动发布

### 重要说明

**当前版本不包含自动发布功能**，原因如下：

1. **没有官方 API** - 小红书没有提供公开的 API 用于自动发布
2. **安全风险** - 浏览器自动化可能被识别为机器人，导致账号风险
3. **登录验证** - 需要处理复杂的验证码和登录流程

### 推荐的发布方式

#### 方式一：手动发布（推荐）

1. 运行 `立即生成.bat` 或等待定时任务
2. 打开 `daily_output/xhs-images/{类别}-{日期}/` 目录
3. 复制 `note-text.txt` 中的文案
4. 手动上传 4 张图片到小红书
5. 粘贴文案并发布

#### 方式二：使用第三方工具

可以考虑使用以下方式（自行评估风险）：
- 小红书创作者平台（网页版）
- 第三方小红书管理工具
- Selenium/Puppeteer 浏览器自动化（需自行开发）

## 🔧 配置说明

### API 密钥配置

当前使用 DashScope（阿里通义万象）生成图片，API 密钥已内置在脚本中。

如需修改：
```javascript
const DASHSCOPE_API_KEY = 'your-api-key';
```

### 图片配置

在 `daily-xhs-generator.js` 中修改：
```javascript
const IMAGE_SIZE = '1536x1536';    // 图片尺寸
const IMAGE_QUALITY = '2k';          // 图片质量
```

## 🐛 常见问题

### Q: 定时任务没有运行？
A: 检查：
1. 脚本窗口是否保持打开
2. 系统时间是否正确
3. 控制台是否有错误信息

### Q: 图片生成失败？
A: 可能原因：
1. API 密钥失效或配额用完
2. 网络连接问题
3. API 速率限制（脚本已包含等待时间）

### Q: 如何只生成某个类别的内容？
A: 编辑 `daily-xhs-generator.js`，注释掉不需要的 `CATEGORIES`
