# 生产上线清单

本文档汇总产品上线前需落实的安全、监控、合规与运维项，并与代码实现对应。

---

## 一、安全

| 项 | 说明 | 实现位置 |
|----|------|----------|
| **SESSION_SECRET** | 生产使用强随机串（≥32 字符），禁止默认值 | `lib/session.ts` 生产环境校验；`.env.example` 说明 |
| **Cookie** | 生产启用 `secure`、`httpOnly`、`sameSite: 'lax'` | `lib/session.ts` 已按 NODE_ENV 设置 |
| **环境变量** | 密钥仅服务端，不打包进前端 | 仅 `NEXT_PUBLIC_*` 暴露给浏览器 |
| **限流** | 登录、消耗次数、下单等接口按 IP/用户限流 | `lib/rateLimit.ts`；应用于 `/auth/wechat/login`、`/query/consume`、`/vip/create-order` |
| **CORS** | 生产仅允许配置的前端域名 | `next.config.ts` 使用 `ALLOWED_ORIGINS`（多域名时取第一个；需多域名时可在 middleware 中动态设置） |
| **输入校验** | 接口参数校验与长度限制 | 各 API 已有基础校验；登录 `code` 长度 ≤128，下单 `planId` 白名单 |

---

## 二、后端监控与可观测

| 项 | 说明 | 实现位置 |
|----|------|----------|
| **Sentry 服务端** | API / SSR 未捕获异常上报 | `sentry.server.config.ts`、`sentry.edge.config.ts` 已配置 |
| **结构化日志** | 关键操作打日志（不含密码等敏感信息） | `lib/logger.ts`；登录、消耗次数、下单等调用 |
| **健康检查** | 供负载均衡/平台探活 | `GET /api/health`（可选 DB/Redis 检查） |
| **告警** | 5xx、错误突增、耗时由 Sentry/云监控告警 | 在 Sentry 控制台配置告警规则 |

---

## 三、数据与合规

| 项 | 说明 | 落实方式 |
|----|------|----------|
| **隐私政策 / 用户协议** | 上线前发布，说明数据收集与用途 | 前端页脚链接 + 文案 |
| **用户同意** | 行为分析、Sentry 等需用户同意时再启用 | 登录或首次使用前勾选/弹窗 |
| **数据保留** | 明确日志、行为数据、Sentry 保留期限 | 运维与 Sentry 后台配置 |
| **用户权利** | 导出/删除账号数据（如 GDPR） | 按需在账号设置中提供入口与后端接口 |

---

## 四、稳定性与运维

| 项 | 说明 | 实现/建议 |
|----|------|----------|
| **数据库** | 定期备份；生产使用 migrate 而非 db push | 使用 `npm run db:migrate`；云数据库开启自动备份 |
| **Redis** | 故障时降级，关注连接数与错误率 | `lib/cache.ts`、`lib/rateLimit.ts` 已有降级 |
| **部署** | 生产环境变量在平台配置 | Vercel/Railway 等配置 `DATABASE_URL`、`SESSION_SECRET` 等 |
| **回滚** | 能快速回滚到上一版本 | 使用平台一键回滚或保留上一镜像 |

---

## 五、业务与支付

| 项 | 说明 | 实现/建议 |
|----|------|----------|
| **支付** | 真实收款需正式商户、回调验签与幂等 | `app/api/pay/wechat/notify` 需按微信支付文档完善 |
| **免费额度防刷** | 同一 IP/设备注册与消耗限制 | `lib/rateLimit.ts` 对登录与 consume 限流 |
| **敏感操作** | 下单等可加二次确认 | 前端确认弹窗已存在；可按需加强 |

---

## 六、环境变量速查

生产环境需配置（见 `.env.example` 详细说明）：

- `DATABASE_URL`：PostgreSQL 连接串
- `SESSION_SECRET`：≥32 字符随机串（生产必须自定义）
- `UPSTASH_REDIS_URL`：可选，用于缓存与限流
- `NEXT_PUBLIC_SENTRY_DSN`：前端/后端 Sentry
- `ALLOWED_ORIGINS`：生产 CORS 允许的前端域名，逗号分隔

---

## 七、上线前自检

- [ ] 生产 `SESSION_SECRET`、`DATABASE_URL`、支付相关密钥已安全配置
- [ ] CORS 仅允许生产前端域名（`ALLOWED_ORIGINS`）
- [ ] 全站 HTTPS；Cookie 为 secure
- [ ] 登录、消耗次数、下单等接口已限流
- [ ] 后端异常已接入 Sentry
- [ ] `GET /api/health` 可被探活
- [ ] 隐私政策与用户协议已上线；行为分析/Sentry 合规与用户同意已处理
- [ ] 数据库有备份与迁移流程；Redis 故障可降级
- [ ] 若上线真实支付，已完成联调与回调验证
